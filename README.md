# Bot discord para WL de servidores de jogos

Bot discord para WL de servidores de jogos mas o principal aqui é o jogo FiveM feito com javascript e tenha obrigatoriamente o node instalado na versão mais atualizada +22 anterior a essa 22 não vai funcionar bem para cidades bases e etc...

OBS: não precisa ajustar mais nada após colocar as credenciais em .env.example após colocar elas tire o .example para não ser mais exemplo fecho?! tudo e configurado database TUDO via o bot com os comandos slash após o deploy dos comandos!

## Comandos para instalar e iniciar e já rodar

Na mesma pasta onde ta o .env abra o cmd e aponte para ela via cd, exemplo: cd C:\bot-cidade-fivem após isso vamos iniciar os comandos:

```bash
npm install
```
Execute esse primeiramente para instalar todas as dependecias que ainda não foram instaladas!

```bash
npm run deploy
```
Aqui é a chave! onde vc vai realizar o deploy do seu bot para mostrar os comandos slash já no seu servidor se configurado corretamente o .env como dito anteriormente

```bash
npm start
```
Aqui onde vc starta todo o bot e todos os comandos e etc.. já estaram funcionando se configurado corretamente o .env


## Requirements

- node na versão maior que +22
- uma VPS para rodar 24/7 o bot
- saber o basico de discord.dev pra criar o seu bot e configurar o .env
- o resto é facil e simplis via comandos lindos e perfeitos slash ( comandos de / do propio bot sem prefix ! )
